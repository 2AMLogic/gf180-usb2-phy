# spec

Ratified specification and decision records.

- [`usb2-device-phy.md`](usb2-device-phy.md) — the ratified block
  specification (issue #1). Section 12 is its decision log; §12.1 indexes
  the post-ratification decision records below.
- [`decisions/`](decisions/) — numbered decision records (`DR-NNNN`) for
  trade-offs settled *after* ratification: one file per decision, stating
  the alternatives that were live, the call, and the conditions attached to
  it. A decision record never changes a ratified value — if a change to
  `usb2-device-phy.md` itself is ever needed, that is an amendment to the
  relevant section, made with its own rationale.
