     the resolved PDK deck's own minimum width for

     metal1 route in the block from 0.23 to 0.28 µm — including the great
     majority that never touch metal2. 0.28 µm is still ≥ the metal1 minimum
     and the result is DRC-clean, so this is a density cost, not a
     correctness one, and the plan commits 0.28. Filed generically upstream

     The failure message itself is good and made the constraint findable —
